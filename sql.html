Lenguaje SQL (Structured Query Language)

Comandos básicos DDL, DML y uniones con INNER JOIN

1. DDL: Definición de la Estructura

Creación de Tabla (CREATE TABLE)
CREATE TABLE Alumnos (
    id_alumno INT PRIMARY KEY,
    nombre VARCHAR(50),
    apellido VARCHAR(50),
    id_curso INT
);
Borrado Completo (DROP)
Atención: DROP elimina de la base de datos la tabla entera junto con todos sus registros. 
DROP TABLE Alumnos;
DROP DATABASE Escuela;

2. DML: Consultas y Manipulación de Datos

Insertar Registros (INSERT INTO)
INSERT INTO Alumnos 
VALUES (1, 'Lucas', 'Gómez', 4);
Consultar con Filtro (SELECT + WHERE)
SELECT nombre, apellido 
FROM Alumnos 
WHERE id_curso = 4;
Actualizar Registro (UPDATE)
UPDATE Alumnos 
SET id_curso = 5 
WHERE id_alumno = 1;
Eliminar Fila (DELETE)
DELETE FROM Alumnos 
WHERE id_alumno = 1;

3. Relacionar Tablas: INNER JOIN

El comando INNER JOIN sirve para cruzar información entre dos tablas utilizando una Clave Primaria (PK) de una tabla y su correspondiente Clave Foránea (FK) en la otra. 

SELECT Alumnos.nombre, Alumnos.apellido, Cursos.nombre_curso
FROM Alumnos
INNER JOIN Cursos 
ON Alumnos.id_curso = Cursos.id_curso;
